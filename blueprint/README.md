# Lean Blueprint 日本語解説

`src/web.tex` は公式 Lean Blueprint パッケージを読み込み、本文で `\lean`、`\leanok`、`\uses` を使います。
英語版と同じ34ノード・56宣言を日本語で説明します。原稿の定理1.4の全節を含みます。

`formal/` の既存配置を保つため、ラッパーから plasTeX を直接呼びます。
宣言検査は固定した英語版の Lean 環境で行い、リンク先のソースもその版から生成します。
`leanblueprint checkdecls` を設定済みとは主張しません。ルート README のコマンドを使ってください。

依存図は主要部分の解説図です。全宣言の網羅、自然言語の自動認証、人間の査読完了を意味しません。
