# 対象と最終四定理

`pᵢ ≥ 2`、`Σ1/pᵢ < 1` に対し、捩れを保持した実商群
`L = (ℤⁿ ⊕ ℤc)/⟨pᵢxᵢ − c⟩` と、実際の商環
`T = ℂ[X]/(Σ Xᵢ^pᵢ)` を構成します。`aτ = c − Σxᵢ` を満たす
実際の `τ ∈ L` から `R = ⊕ₘ≥₀ Tₘτ` を部分代数として定めます。

対象は、この R が正重み・非零斉次式・定数項一次項なし・原点のみの勾配零点を
持つ超曲面表示と次数付き同型になる場合です。`Target` は列挙器と独立に定義されます。
最小生成元数と実際の Ext¹ 標準加群のシフトは、対象から導く結論です。

| 宣言 | 保証 |
| --- | --- |
| `CanonicalRoots.enumerate_sound` | 各出力は実際の対象を実現し、整列した正の原始重み、非負指数、根の証人、最小生成元数、標準 Ext のシフトを持つ。 |
| `CanonicalRoots.enumerate_complete` | 任意の実対象と次数付き同型な出力位置がただ一つ存在する。 |
| `CanonicalRoots.enumerate_pairwise_nonisomorphic` | 異なる出力位置は実際の次数付き複素代数として非同型である。 |
| `CanonicalRoots.cli_payload_correct` | 純粋 JSON payload の復号は全列挙結果と一致する。 |

三変数枝は五型への帰着・実根環への実現・キーによる実同型分類を接続します。
4変数以上の枝は有限指標の実商環作用、R=T^G、局所安定化群の不変環から
互いに素性を導き、最大根性と R=T を経て整数再帰に結び付けます。

OS 出力、コンパイラー、JSON 文字列の parser/printer、外部ハッシュは
純粋定理の外側です。実機での実用的な時間・メモリの保証も全域性とは別です。

## 可逆性と剛性の定理（原稿の定理1.4）

`canonical_root_isolated_ja_v01.pdf` の4ページの定理1.4は、
英語正本の `formal/CanonicalRoots/TheoremOneFour.lean` にある
`CanonicalRoots.theorem_1_4` と対応します。原稿の `δ` は Lean の `a` です。
六つの連言が次を述べます。

1. 全ての孤立超曲面根環は、原始重みと
   `Ew = h1`、`|det E| = h`、`h = a + Σwᵢ` を満たす可逆表示を持つ。
2. この条件を満たす任意の三変数可逆多項式は、その多項式・重み・次数のまま
   実際の根環の表示になる。非零係数は任意の複素数でよい。
3. 同じ正の根指数を持つ次数付き同型な三変数根環の signature は、
   順序を除いて一致する。
4. 同じ signature と正の根指数に対する根は一意である。
5. 四変数以上では、指数の対ごとの互いに素性と
   `Πpᵢ − ΣᵢΠⱼ≠ᵢpⱼ = a` が、孤立超曲面根環が存在するための必要十分条件である。
6. この場合は実部分環として `R = T` であり、関係式次数 `h = Πpᵢ`、
   重み `wᵢ = h/pᵢ` の原始 Fermat 表示を持つ。他の正の根指数は全て `a` を割り切り、
   `a` 以下なので `a` は最大である。

逆方向の入力 `InvertiblePolynomial` は、実多項式の項、非零係数、正則な指数行列、
正重みの斉次性、定数項と一次項の不在、孤立性だけから定義されます。
五つの型への帰着や根環としての実現を仮定していません。
支持の分類、対角変換による係数正規化、実商環の次数付き同型を順に証明しています。
順方向では適切な表示の存在を主張しており、最初に与えられた全ての方程式の行列式が
`h` に等しいと主張するものではありません。
