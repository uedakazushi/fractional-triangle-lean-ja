# 対象と最終四定理

`pᵢ ≥ 2`、`Σ1/pᵢ < 1` に対し、捩れを保持した実商群
`L = (ℤⁿ ⊕ ℤc)/⟨pᵢxᵢ − c⟩` と、実際の商環
`T = ℂ[X]/(Σ Xᵢ^pᵢ)` を構成します。`aτ = c − Σxᵢ` を満たす
実際の `τ ∈ L` から `R = ⊕ₘ≥₀ Tₘτ` を部分代数として定めます。

対象は、この R が正重み・非零斉次式・定数項一次項なし・原点のみの勾配零点を
持つ超曲面表示と次数付き同型になる場合です。`Target` は列挙器と独立に定義されます。
最小生成元数と実際の Ext¹ 標準加群のシフトは、対象から導く結論です。

| 宣言 | 保証 |
| --- | --- |
| `CanonicalRoots.enumerate_sound` | 各出力は実際の対象を実現し、整列した正の原始重み、非負指数、根の証人、最小生成元数、標準 Ext のシフトを持つ。 |
| `CanonicalRoots.enumerate_complete` | 任意の実対象と次数付き同型な出力位置がただ一つ存在する。 |
| `CanonicalRoots.enumerate_pairwise_nonisomorphic` | 異なる出力位置は実際の次数付き複素代数として非同型である。 |
| `CanonicalRoots.cli_payload_correct` | 純粋 JSON payload の復号は全列挙結果と一致する。 |

三変数枝は五型への帰着・実根環への実現・キーによる実同型分類を接続します。
4変数以上の枝は有限指標の実商環作用、R=T^G、局所安定化群の不変環から
互いに素性を導き、最大根性と R=T を経て整数再帰に結び付けます。

OS 出力、コンパイラー、JSON 文字列の parser/printer、外部ハッシュは
純粋定理の外側です。実機での実用的な時間・メモリの保証も全域性とは別です。
